What it does

A developer-grade traffic inspector that never leaves the device.

📡

Live traffic feed

Capture HTTP/HTTPS calls from the apps you select, with method, status, host, timing and size — filter by method, status, app or “has token”.

🔑

Token & JWT inspector

Auto-extracts Bearer / API-key / Cookie credentials and decodes JWT header & payload with expiry — one tap to copy.

🧰

cURL generator

Turn any captured request into a ready-to-run, shell-safe cURL command. Copy or share.

📦

Export

Export the whole session as HAR 1.2, a Postman v2.1 collection, or a runnable cURL bundle.

🔒

On-device MITM

A local proxy + VpnService intercept your selected apps’ traffic. Install the local CA to decrypt HTTPS. Nothing is sent to a server.

🧪

Simulation mode

Realistic mock traffic lets you try the whole UI before touching a real app.

Install

Two minutes, no computer required.

  1. Download the APK from the button above (or the Releases page) directly on your phone.
  2. Allow install from your browser/file manager when Android prompts about unknown sources.
  3. Open NetPulse → Cert tab → Install certificate to trust the local CA (needed to decrypt HTTPS).
  4. Pick a target app on the Targets tab, then hit Start Capture and approve the VPN prompt.

Prefer to build it yourself? Clone the repo and run the GitHub Actions workflow, or npx expo run:android.

Scope & ethics

NetPulse inspects traffic on your own device for development and authorized security testing. Decrypting HTTPS requires installing a local CA you control; apps that use certificate pinning will not be decryptable. Only inspect apps and devices you are authorized to test.

Build from source

git clone https://github.com/EngAbdalrhman/netpulse
cd netpulse
npm install --legacy-peer-deps
npx expo run:android   # or trigger the GitHub Actions build
